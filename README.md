# vkstream

Telegram-бот, который пересылает вам в личку новые сообщения из ВКонтакте по
простым правилам:

| Что | Правило |
|---|---|
| 👤 Личные сообщения | пересылаются все, автоматически |
| 👥 Группы (беседы) и 📣 каналы | по вашему выбору: при первом сообщении бот спросит, оставить или заблокировать |
| 📰 Стена сообщества | новые записи — если вы добавили сообщество ссылкой (`/add`) |
| 🏢 Бизнес и реклама (диалоги с сообществами) | не пересылаются |

Выбор запоминается для каждого чата отдельно, и его можно поменять в `/settings`.

> Неофициальный проект, не связан с VK и Telegram. Бот работает от имени вашей
> веб-сессии vk.ru — так же, как открытая вкладка браузера. Используйте на свой
> страх и риск: VK может ограничить такой доступ.

## Как это работает

С 7 сентября 2026 года VK ввёл лимиты на API, из-за которых сторонние клиенты
(Kate Mobile и другие) перестали работать, поэтому привычный способ «взять токен
Kate Mobile» больше не годится. Бот делает то же, что сайт vk.ru в браузере:

1. вы один раз входите в ВК в окне браузера — на диск сохраняются только cookie
   сессии, пароль программа не видит;
2. по cookie бот получает короткоживущий токен веб-клиента
   (`login.vk.ru/?act=web_token`) и сам обновляет его;
3. long poll мессенджера служит сигналом «что-то произошло»: по нему бот
   сверяет список чатов и читает новое методом `messages.getHistory`;
4. раз в минуту сверка идёт и без сигнала — если long poll что-то пропустил или
   бот был выключен, сообщения всё равно дойдут. Тогда же проверяются каналы и
   папка «Запросы» (сообщения не от друзей): своих сигналов у них нет.

При первом запуске бот только запоминает, какие чаты у вас есть: старая
переписка не пересылается, вопросы обо всех группах сразу не задаются.

## Установка

Нужны Python 3.11+ и Google Chrome (для входа в ВК; подойдут также Chromium,
Edge и Brave, другой браузер на Chromium задаётся переменной `VKSTREAM_BROWSER`).

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

В `.env` впишите `TG_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather).

## Запуск

**1. Подключите аккаунт ВК**

```bash
.venv/bin/python -m vkstream login
```

Откроется окно Chrome со страницей vk.ru — войдите в аккаунт, окно закроется само.
Это обычный Chrome с пустым временным профилем: программа только читает из него
cookie сессии, а профиль после входа удаляется.
Если окно открыть нельзя (сервер без экрана), используйте
`python -m vkstream login --cookie` и вставьте заголовок `Cookie` из DevTools.

**2. Проверьте, что всё настроено**

```bash
.venv/bin/python -m vkstream check
```

**3. Запустите бота**

```bash
.venv/bin/python -m vkstream
```

При первом запуске бот напечатает ссылку вида `https://t.me/<бот>?start=<код>`.
Откройте её и нажмите «Запустить» — так бот запомнит вас как владельца. Все
остальные пользователи для него не существуют. (Вместо этого можно указать
`TG_OWNER_ID` в `.env`.)

## Как устроен выбор

Когда в группе или канале, о которых вы ещё ничего не решили, появляется новое
сообщение, бот пересылает его и спрашивает:

> ❓ 👥 **Рабочий чат**
> Пересылать сюда сообщения из этой группы? Пока не ответите, новые придержу.
> `✅ Оставить` `🚫 Заблокировать`

- **Оставить** — придут придержанные сообщения, дальше чат пересылается сам.
- **Заблокировать** — чат замолкает; спрашивать о нём бот больше не будет.

Правило категории можно обойти для отдельного чата: заблокировать конкретного
человека или, наоборот, разрешить один нужный магазин.

## Команды бота

| Команда | Что делает |
|---|---|
| `/settings` | разделы «Личные / Группы / Каналы / Бизнес» со списками чатов; нажатие на чат переключает ✅ ↔ 🚫 |
| `/add ссылка` | пересылать новые записи со стены сообщества; ссылку вида `vk.ru/club1` можно прислать и без команды |
| `/find текст` | поиск чата по названию во всех разделах; можно просто написать название без команды |
| `/status` | подключён ли ВК, как приходят сообщения, сколько чатов в каждом разделе |

Если чат разблокировать, придут только сообщения, написанные после этого.

### Сообщества со стеной

Обычная группа или паблик — это не чат: её записи лежат на стене, и в списке
диалогов её нет. Чтобы получать новые записи, пришлите боту ссылку на сообщество:

```
/add https://vk.ru/club129312036
```

Старые записи не пересылаются, новые приходят с кнопкой «Открыть в VK»; репост
показывается как пересланная запись. Стена проверяется раз в 5 минут
(`WALL_POLL_INTERVAL`). Отключить сообщество можно в `/settings` → «Каналы».
Стена закрытой группы читается, только если ваш аккаунт в ней состоит.

## Что пересылается

- текст, упоминания, ответы (цитатой) и пересланные сообщения (вложенно);
- фото и стикеры — картинками, несколько фото — альбомом;
- голосовые — голосовыми, с расшифровкой, если её сделал VK;
- документы и GIF — файлами (до 49 МБ, больше — ссылкой);
- видео, ссылки, записи со стены, опросы, геометки — текстом со ссылкой;
- служебные события беседы (пригласили, закрепили, переименовали).

Под каждым сообщением — кнопка «Открыть в VK». Свои исходящие сообщения по
умолчанию не пересылаются (`FORWARD_OUTGOING=true`, чтобы включить).

## Ограничения

- Это только чтение: отвечать в ВК из Telegram нельзя.
- Правки и удаления сообщений не отслеживаются.
- **Каналы** читаются недокументированными методами веб-клиента (`channels.*`),
  их формат взят из открытых клиентов и на живом аккаунте мной не проверен.
  `python -m vkstream check` покажет, читаются ли они у вас; если нет — всё
  остальное работает как обычно, а `/status` назовёт причину. Посты каналов
  приходят с задержкой до минуты и без кнопки «Открыть в VK».
- Сообщения не от друзей (папка «Запросы») тоже приходят с задержкой до минуты.
- Рекламу от обычных пользователей бот от личных сообщений отличить не может —
  такого собеседника можно заблокировать через `/find`.
- Чаты, которые вы убрали в архив ВК, не отслеживаются, пока они оттуда не выйдут.
- Если бот был выключен, он догонит до 50 последних сообщений на чат
  (`HISTORY_COUNT`, максимум 200).
- Когда сессия ВК перестанет действовать, бот напишет об этом — повторите
  `python -m vkstream login`, перезапускать бота не нужно.

## Безопасность

`data/vk_session.json` — это доступ к вашему аккаунту ВК, включая личные
сообщения. Файл создаётся с правами `0600` и исключён из git вместе с `.env`.
Никому его не передавайте. Чтобы отозвать доступ, завершите сеанс в настройках
безопасности VK ID.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TG_BOT_TOKEN` | — | токен бота |
| `TG_OWNER_ID` | — | Telegram ID владельца (иначе — привязка по ссылке) |
| `TG_PROXY`, `VK_PROXY` | — | прокси `http://…` или `socks5://…` |
| `FORWARD_OUTGOING` | `false` | пересылать и свои сообщения |
| `POLL_INTERVAL` | `60` | период страховочной сверки, сек |
| `WALL_POLL_INTERVAL` | `300` | период проверки стен сообществ, сек |
| `DATA_DIR` | `./data` | где лежат сессия и состояние |

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Тесты поднимают поддельный сервер ВК (вход, API, long poll) и подменяют сеть
Telegram, так что настоящие аккаунты не нужны.

## На чём основано

Протокол веб-мессенджера и общий подход взяты из открытых проектов:

- [JacobMaxbetov/vk2tg](https://github.com/JacobMaxbetov/vk2tg) — мост VK → Telegram
  на long poll веб-клиента (`messages.getDiff`, `web.api.vk.ru`);
- [PerformanC/NodeLink](https://github.com/PerformanC/NodeLink),
  [ilyhalight/vk-audio](https://github.com/ilyhalight/vk-audio) — обновление
  токена по cookie через `act=web_token`;
- [TolyaGosuslugi/vk2tg-post](https://github.com/TolyaGosuslugi/vk2tg-post),
  [magnickolas/vk2tg-bot](https://github.com/magnickolas/vk2tg-bot) — классический
  User Long Poll.

- [pinokio240/PinoK_1](https://github.com/pinokio240/PinoK_1),
  [eremeyko/VKArchive](https://github.com/eremeyko/VKArchive) — методы каналов
  (`channels.get`, `channels.getHistory`) и папка «Запросы».

В отличие от них, события long poll здесь не разбираются, а служат только
сигналом «пора свериться»: формат событий веб-клиента не документирован и
меняется, а чтение по курсору `conversation_message_id` от него не зависит.
