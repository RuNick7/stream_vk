# vkstream

Telegram-бот, который пересылает вам в личку новые сообщения из выбранных чатов
ВКонтакте: личных диалогов, бесед и диалогов с сообществами. Чаты выбираются
кнопками прямо в боте.

> Неофициальный проект, не связан с VK и Telegram. Бот работает от имени вашей
> веб-сессии vk.ru — так же, как открытая вкладка браузера. Используйте на свой
> страх и риск: VK может ограничить такой доступ.

## Как это работает

С 7 сентября 2026 года VK ввёл лимиты на API, из-за которых сторонние клиенты
(Kate Mobile и другие) перестали работать, поэтому привычный способ «взять токен
Kate Mobile» больше не годится. Бот делает то же, что сайт vk.ru в браузере:

1. вы один раз входите в ВК в окне браузера — на диск сохраняются только cookie
   сессии, пароль программа не видит;
2. по cookie бот получает короткоживущий токен веб-клиента
   (`login.vk.ru/?act=web_token`) и сам обновляет его;
3. о новых сообщениях узнаёт через long poll мессенджера, а сами сообщения
   читает методом `messages.getHistory`;
4. раз в минуту дополнительно сверяет выбранные чаты — если long poll что-то
   пропустил или бот был выключен, сообщения всё равно дойдут.

## Установка

Нужны Python 3.11+ и Google Chrome (для входа в ВК).

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

В `.env` впишите `TG_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather).

## Запуск

**1. Подключите аккаунт ВК**

```bash
.venv/bin/python -m vkstream login
```

Откроется окно Chrome со страницей vk.ru — войдите в аккаунт, окно закроется само.
Если окно открыть нельзя (сервер без экрана), используйте
`python -m vkstream login --cookie` и вставьте заголовок `Cookie` из DevTools.

**2. Проверьте, что всё настроено**

```bash
.venv/bin/python -m vkstream check
```

**3. Запустите бота**

```bash
.venv/bin/python -m vkstream
```

При первом запуске бот напечатает ссылку вида `https://t.me/<бот>?start=<код>`.
Откройте её и нажмите «Запустить» — так бот запомнит вас как владельца. Все
остальные пользователи для него не существуют. (Вместо этого можно указать
`TG_OWNER_ID` в `.env`.)

## Команды бота

| Команда | Что делает |
|---|---|
| `/chats` | список диалогов ВК с кнопками: нажали — чат пересылается (✅), ещё раз — нет |
| `/find текст` | поиск чата по названию; можно просто написать название без команды |
| `/list` | что пересылается сейчас, с кнопками удаления |
| `/status` | подключён ли ВК, как приходят сообщения, сколько переслано |

Пересылаются только сообщения, пришедшие **после** выбора чата.

## Что пересылается

- текст, упоминания, ответы (цитатой) и пересланные сообщения (вложенно);
- фото и стикеры — картинками, несколько фото — альбомом;
- голосовые — голосовыми, с расшифровкой, если её сделал VK;
- документы и GIF — файлами (до 49 МБ, больше — ссылкой);
- видео, ссылки, записи со стены, опросы, геометки — текстом со ссылкой;
- служебные события беседы (пригласили, закрепили, переименовали).

Под каждым сообщением — кнопка «Открыть в VK». Свои исходящие сообщения по
умолчанию не пересылаются (`FORWARD_OUTGOING=true`, чтобы включить).

## Ограничения

- Это только чтение: отвечать в ВК из Telegram нельзя.
- Правки и удаления сообщений не отслеживаются.
- «Каналы» VK в список диалогов не входят.
- Если бот был выключен, он догонит до 50 последних сообщений на чат
  (`HISTORY_COUNT`, максимум 200).
- Когда сессия ВК перестанет действовать, бот напишет об этом — повторите
  `python -m vkstream login`, перезапускать бота не нужно.

## Безопасность

`data/vk_session.json` — это доступ к вашему аккаунту ВК, включая личные
сообщения. Файл создаётся с правами `0600` и исключён из git вместе с `.env`.
Никому его не передавайте. Чтобы отозвать доступ, завершите сеанс в настройках
безопасности VK ID.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TG_BOT_TOKEN` | — | токен бота |
| `TG_OWNER_ID` | — | Telegram ID владельца (иначе — привязка по ссылке) |
| `TG_PROXY`, `VK_PROXY` | — | прокси `http://…` или `socks5://…` |
| `FORWARD_OUTGOING` | `false` | пересылать и свои сообщения |
| `POLL_INTERVAL` | `60` | период страховочной сверки, сек |
| `DATA_DIR` | `./data` | где лежат сессия и состояние |

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Тесты поднимают поддельный сервер ВК (вход, API, long poll) и подменяют сеть
Telegram, так что настоящие аккаунты не нужны.

## На чём основано

Протокол веб-мессенджера и общий подход взяты из открытых проектов:

- [JacobMaxbetov/vk2tg](https://github.com/JacobMaxbetov/vk2tg) — мост VK → Telegram
  на long poll веб-клиента (`messages.getDiff`, `web.api.vk.ru`);
- [PerformanC/NodeLink](https://github.com/PerformanC/NodeLink),
  [ilyhalight/vk-audio](https://github.com/ilyhalight/vk-audio) — обновление
  токена по cookie через `act=web_token`;
- [TolyaGosuslugi/vk2tg-post](https://github.com/TolyaGosuslugi/vk2tg-post),
  [magnickolas/vk2tg-bot](https://github.com/magnickolas/vk2tg-bot) — классический
  User Long Poll.

В отличие от них, события long poll здесь не разбираются, а служат только
сигналом «в чате что-то новое»: формат событий веб-клиента не документирован и
меняется, а чтение по курсору `conversation_message_id` от него не зависит.
